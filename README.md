# Vage Clothing

A modern clothing e-commerce web application built with React and Tailwind CSS.

## Features

- Product browsing and category navigation
- Product detail pages
- Shopping cart management
- Client-side routing
- Responsive UI
- Toast notifications
- Reusable React components
- Animated UI interactions

## Tech Stack

- React
- JavaScript
- React Router
- Tailwind CSS
- Vite
- Framer Motion
- Lucide React

## Project Structure

src/
├── components/
├── context/
├── data/
├── lib/
├── pages/
└── assets/

## Getting Started

npm install
npm run dev
